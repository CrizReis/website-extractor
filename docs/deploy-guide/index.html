Deploy Guide

Website Extractor

Guia completo para hospedar o Website Extractor na Hostinger VPS com Docker, domínio customizado e SSL.

Hostinger VPS Docker Python 3.11

Antes de começar

  • ✓
    Conta GitHub — com acesso ao repositório website-extractor
  • ✓
    Hostinger VPS ativo — plano KVM 1 ou superior (4 GB RAM mínimo). Anote o IP do servidor.
  • ✓
    Domínio configurado — domínio ou subdomínio que você quer apontar para o app
  • ✓
    Terminal SSH — acesso via terminal (Windows Terminal, iTerm2, Putty, ou o terminal integrado da Hostinger)
1

Subir o código no GitHub

Publique o repositório customizado no seu perfil do GitHub para o servidor conseguir baixar.

No computador, abra o terminal dentro da pasta D:\website-extractor e execute:

PowerShell / Terminal 
cd D:\website-extractor
git remote remove origin
git remote add origin https://github.com/SEU-USUARIO/website-extractor.git
git add .
git commit -m "feat: customizacao branding Website Extractor"
git push -u origin main
ℹ Substitua SEU-USUARIO pelo seu usuário do GitHub. O repositório deve ser público para o servidor conseguir clonar sem autenticação.
2

Acessar o VPS via SSH

Conecte ao servidor da Hostinger pelo terminal.

No painel da Hostinger, vá em VPS → Manage e copie o IP do servidor. Depois conecte via SSH:

Terminal 
ssh root@IP_DO_VPS

A Hostinger também oferece um terminal diretamente no painel web em VPS → Terminal, caso prefira não usar SSH local.

3

Instalar Docker no servidor

O app roda em container Docker — instale uma única vez e nunca mais precisa mexer.

Execute o script oficial de instalação do Docker:

Servidor (SSH) 
curl -fsSL https://get.docker.com | sh
systemctl enable docker
systemctl start docker

Verifique se funcionou:

Servidor (SSH) 
docker --version
ℹ Se o servidor já tiver Docker instalado, pule esta etapa.
4

Clonar o repositório e rodar o app

Baixe o código e suba o container — o app estará acessível na porta 8080.

Servidor (SSH) 
git clone https://github.com/SEU-USUARIO/website-extractor.git /app/website-extractor
cd /app/website-extractor
docker build -t website-extractor .
docker run -d \
  --name website-extractor \
  --restart unless-stopped \
  -p 8080:8080 \
  website-extractor
⚠ O build leva de 3 a 8 minutos na primeira vez — o Docker precisa baixar o Python, instalar dependências e o Chromium. É normal a espera.

Para confirmar que está rodando:

Servidor (SSH) 
docker ps

Você deve ver website-extractor com status Up.

5

Apontar o domínio para o VPS

Configure o DNS para que seu domínio resolva para o IP do servidor.

No painel do seu provedor de domínio (Hostinger, Cloudflare, etc.), crie o seguinte registro DNS:

Tipo Nome / Host Valor TTL
A @ (domínio raiz) ou extractor (subdomínio) IP_DO_VPS 3600
ℹ A propagação do DNS pode levar até 24h, mas normalmente resolve em menos de 1 hora. Você pode verificar em dnschecker.org.
6

Configurar Nginx e SSL gratuito

Instale o Nginx como proxy reverso e emita o certificado SSL com Certbot.

Instale Nginx e Certbot:

Servidor (SSH) 
apt update && apt install -y nginx certbot python3-certbot-nginx

Crie o arquivo de configuração do Nginx (substitua SEU-DOMINIO.com):

Servidor (SSH) 
cat > /etc/nginx/sites-available/website-extractor << 'EOF'
server {
    listen 80;
    server_name SEU-DOMINIO.com;

    location / {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 300s;
    }
}
EOF

ln -s /etc/nginx/sites-available/website-extractor /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx

Emita o certificado SSL gratuito:

Servidor (SSH) 
certbot --nginx -d SEU-DOMINIO.com
ℹ O Certbot pedirá um e-mail para notificações de renovação. O certificado é renovado automaticamente a cada 90 dias.

Após o Certbot finalizar, o app estará acessível em https://SEU-DOMINIO.com.

7

Como atualizar o app no futuro

Sempre que fizer mudanças no código, repita este processo.

No computador local, publique as alterações no GitHub:

PowerShell / Terminal (local) 
git add .
git commit -m "update: descricao da mudanca"
git push

No servidor, atualize e reconstrua o container:

Servidor (SSH) 
cd /app/website-extractor
git pull
docker build -t website-extractor .
docker stop website-extractor
docker rm website-extractor
docker run -d \
  --name website-extractor \
  --restart unless-stopped \
  -p 8080:8080 \
  website-extractor
